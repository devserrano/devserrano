##  Featured Projects

###  [UrbanRide (BiciOps) – Bicitaxi Fleet Management System](https://github.com/devserrano/UrbanRide)
Full-stack operational platform for bicitaxi fleet administration. Started as an academic project and grew into a working system, presented at a UNAM evaluation.

- Driver, vehicle, maintenance and inspection management
- **Automatic vehicle state machine**: vehicle status updates itself based on inspection results
- Dashboard with operational KPIs, pagination and SPA-style navigation
- Backend refactored from a monolithic `server.js` into a **layered architecture** (routes / controllers / helpers / config)
- Foreign key integrity added through a **transactional migration**
- PostgreSQL with connection pooling, fully **Dockerized** local setup

`Node.js` `Express.js` `PostgreSQL` `Docker` `JavaScript` `REST APIs`
